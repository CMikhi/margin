
# Project Instructions

## Stack
- Next.js, TypeScript, Tailwind CSS
- Prefer existing dependencies and components.
- Follow the repository's established patterns.

## Before implementing
- Inspect relevant files and components.
- Reuse existing abstractions where appropriate.
- For complex changes, propose a short plan first.

## Frontend standards
- Follow the project's design tokens.
- Avoid generic UI patterns unless requested.
- Prioritize hierarchy, spacing, typography, and responsiveness.
- Preserve existing brand identity.
- Use semantic HTML and accessible controls.
- Do not add dependencies unnecessarily.

## Verification
- Run relevant lint, type, and build checks.
- Test changed interactions where practical.
- Inspect desktop and mobile layouts.
- Report any checks that could not be run.

## Safety
- Never expose secrets or credentials.
- Ask before destructive operations or deployments.
